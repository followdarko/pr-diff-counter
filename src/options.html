A personal access token is required. Create it on your personal account — you don't need to own the organization, membership is enough.

Classic

  1. github.com/settings/tokens → Generate new token (classic)
  2. Scope: repo — the top-level checkbox is enough
  3. If the organization uses SAML SSO — Configure SSO → Authorize next to it

Classic has no read-only mode: repo grants full read and write access to every private repository you can reach. That cannot be narrowed — it's a GitHub limitation, so keep the expiration short.

Fine-grained

  1. Open github.com/settings/personal-access-tokens/new
  2. Resource owner → organization
  3. Repository access → Only select repositories → the repositories you need
  4. Permissions → Pull requests: Read-only (Metadata is added automatically)

If the organization is missing from the Resource owner dropdown, it has disabled fine-grained tokens and you need to use classic. If it is listed but requires approval, the token stays Pending until an owner approves it in Settings → Personal access tokens → Pending requests.
